# Gold Signal Assistant

اپلیکیشن Flutter (اندروید) برای تحلیل تکنیکال XAUUSD و اعلام سیگنال.
**فقط تحلیل و هشدار؛ هیچ اتصالی به حساب معاملاتی ندارد و هیچ معامله‌ای باز/بسته/ویرایش نمی‌کند.**
سیگنال تضمین سود نیست و امتیاز ۰ تا ۱۰۰ احتمال برد نیست.

## وضعیت واقعی پروژه (صادقانه)

| بخش | وضعیت |
|-----|-------|
| کد هسته (تحلیل، ریسک، اعتبار سیگنال) | نوشته شده، **کامپایل و اجرا نشده** |
| تست‌های واحد (`test/`) | نوشته شده، **اجرا نشده** |
| رابط کاربری (داشبورد، نمودار، سیگنال‌ها، تنظیمات) | نوشته شده، **روی دستگاه/شبیه‌ساز دیده نشده** |
| منبع داده واقعی | **پیاده‌سازی نشده**؛ فقط داده آزمایشی برچسب‌دار |
| ساخت APK | فقط از طریق GitHub Actions طراحی شده، **اجرا نشده** |
| اعلان‌ها | فقط وقتی برنامه باز/در پیش‌زمینه است. سرویس پس‌زمینه ندارد |
| بک‌تست | پیاده‌سازی نشده |
| تقویم اخبار | پیاده‌سازی نشده (برنامه ادعای بررسی اخبار نمی‌کند) |

بخش ۱۱ سند مشخصات (صفحات رابط کاربری) از «صفحه نمودار» به بعد ناقص بود؛ نمودار، سیگنال‌ها
و تنظیمات بر اساس بخش‌های کامل ساخته شد.

## ساخت APK

### روش ۱: GitHub Actions (پیشنهادی؛ بدون نصب Flutter)
1. پوشه پروژه را در یک مخزن GitHub بگذارید و push کنید.
2. در تب Actions اجرای «Test and build APK» تمام می‌شود.
3. فایل `app-release.apk` را از Artifacts دانلود و نصب کنید.
اگر `flutter analyze` یا `flutter test` خطا داد، خروجی را بفرستید تا اصلاح شود.

### روش ۲: روی کامپیوتر خودتان
```bash
flutter create --platforms=android --org com.goldsignal --project-name gold_signal_assistant .
python3 tool/patch_android.py
flutter pub get
flutter test
flutter run            # دستگاه/شبیه‌ساز
flutter build apk --release
```
`tool/patch_android.py` دسترسی‌های INTERNET و اعلان، minSdk 23 و desugaring را اضافه می‌کند.
Diff آن را بررسی کنید؛ روی همه نسخه‌های Flutter آزمایش نشده است.

### حداقل نسخه اندروید
`minSdk 23` (Android 6.0). دلیل: `flutter_secure_storage` به API 23 نیاز دارد.
اعلان‌ها روی Android 13+ مجوز زمان اجرا می‌خواهند (برنامه درخواست می‌دهد).

## ساختار
```
lib/core/        منطق خالص Dart (بدون UI): مدل‌ها، اندیکاتورها، ساختار بازار،
                 سطوح، الگوهای کندلی، ریسک، موتور سیگنال، اعتبارسنجی
lib/data/        رابط Market Data Provider، داده آزمایشی، ذخیره‌سازی، اعلان
lib/app/         Riverpod: تنظیمات و کنترلر بازار
lib/ui/          صفحات (RTL، فارسی، Material 3)
test/            تست‌ها
docs/PROVIDERS.md  چک‌لیست و راهنمای منبع داده
```
نمودار با `CustomPainter` رسم می‌شود (وابستگی کمتر و کنترل کامل روی ناحیه‌ها و خطوط معامله).
برای ذخیره‌سازی از `sqflite` و `shared_preferences` استفاده شده، نه Drift (بدون تولید کد).

## قوانین مهم پیاده‌سازی‌شده
* سیگنال قابل معامله فقط روی M1 و M5؛ M15/M30/H1 فقط تأییدکننده‌اند.
* فقط کندل‌های **بسته‌شده**؛ Swing فقط بعد از تأیید (بدون look-ahead).
* حجم ثابت ۰٫۰۱ لات؛ موتور هرگز حجم یا حد ضرر را برای جا شدن در ریسک تغییر نمی‌دهد (رد می‌کند).
* ریسک قیمتی ≤ ۵ دلار؛ «ریسک ویژه» تا ۱۰ دلار فقط با فعال‌کردن دستی.
* نسبت سود به زیان **خالص** ۱:۳: `هدف ناخالص = 3×(R+C)+C` (تست‌شده با مثال سند: R=5, C=2 ← 23).
* داده قدیمی، اسپرد زیاد، اختلاف با قیمت MT5، نوسان غیرعادی ← صدور سیگنال متوقف.
* هر سیگنال زمان انقضا دارد و با رسیدن به حد ضرر، تغییر ساختار، قدیمی‌شدن داده یا افت R:R لغو و اعلام می‌شود.
* سواپ فقط نمایشی است و در محاسبه نیست.
* `RSI` و الگوی کندلی هرگز تنها سیگنال نمی‌سازند. EMA200 نمایشی است، نه فیلتر قطعی.

## تصمیم‌های من که باید بدانید
* `SignalValidator.rrTolerance = 0.1`: یک تیک اسپرد، سیگنال تازه را فوراً لغو نکند. موتور هنگام ساخت سیگنال حداقل کامل را می‌خواهد.
* وزن‌های امتیاز و آستانه‌ها (ناحیه نزدیک = ۱ ATR، بافر حد ضرر = ۰٫۲۵ ATR، حداقل حد ضرر = ۰٫۸ ATR) **حدس اولیه‌اند و بک‌تست نشده‌اند**.
* اسپرد تخمینی پیش‌فرض ۰٫۳۰ و کمیسیون ۱٫۰ دلار است؛ با شرایط واقعی حساب خودتان جایگزین کنید.
