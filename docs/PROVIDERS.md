# انتخاب منبع داده XAUUSD

وضعیت: **هیچ منبع واقعی هنوز پیاده‌سازی یا آزمایش نشده است.**
در محیطی که این پروژه ساخته شد دسترسی اینترنت آزاد وجود نداشت، پس هیچ API
(TickerLayer، FinaQuotes یا دیگران) آزمایش نشد. هیچ‌کدام را «قطعی» یا «رایگان»
فرض نکرده‌ام. فعلاً فقط `MockMarketDataProvider` (داده آزمایشی، برچسب‌دار) وجود دارد.

## آزمایش کوچک (روی گوشی یا کامپیوتر خودتان)

1. کلید را بگیرید و فقط در متغیر محیطی/Secure Storage بگذارید (نه در Git).
2. یک درخواست قیمت و ۵۰ کندل M1 بزنید؛ زمان آخرین کندل را با MT5 مقایسه کنید.
3. چند دقیقه قیمت را کنار نمودار XAUUSD در MT5 ببینید؛ اختلاف معمول را یادداشت کنید
   و `حداکثر اختلاف با قیمت MT5` را بر اساس آن تنظیم کنید.

## پیاده‌سازی یک منبع جدید

`lib/data/market_data_provider.dart` را پیاده‌سازی کنید:

* `fetchQuote()` → `Quote` (اگر Bid/Ask ندارد، `bid`/`ask` را null بگذارید).
* `fetchCandles(tf)` → فقط کندل‌های **بسته‌شده**، صعودی، زمان UTC.
  اگر منبع فقط M1 می‌دهد، با `aggregateCandles` بقیه را بسازید.
* سپس در `MarketController._provider` (فایل `lib/app/providers.dart`) آن را انتخاب کنید.

موتور تحلیل (`lib/core`) به منبع وابسته نیست و نیازی به تغییر ندارد.

## کلید API

کلیدی که داخل APK یا گوشی کاربر می‌ماند کاملاً محرمانه نیست. برای استفاده جدی،
بهتر است یک سرویس واسط (relay) کوچک کلید را نگه دارد و اپ فقط با آن صحبت کند.
